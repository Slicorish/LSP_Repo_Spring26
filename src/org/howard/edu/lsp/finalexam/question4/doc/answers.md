Question: In 1–2 paragraphs, answer the following:
Has your perspective on using AI in programming changed over the semester? Briefly explain.
How do you plan to use AI in future programming or coursework

Answer: 

My perspective on using AI in programming has changed significantly over the course of this semester. Before taking this class, I was skeptical about relying on AI for coding because I believed developers should fully understand every aspect of their projects, from design to implementation without assistance. I assumed using AI was considered as a way of cutting corners. However, this course introduced me to a more practical and realistic approach. I learned that “vibe-coding,” is not only acceptable but often encouraged. Instead of expecting myself to know everything, I’ve learned how to ask intentional, well-structured prompts to get meaningful support. For example, I’ve used AI to debug errors I couldn’t immediately identify, generate alternative implementations of functions, and explain unfamiliar concepts in java implementation or design patterns. One of the most valuable ways I’ve used AI is by comparing my own code to AI-generated solutions. This helped me identify inefficiencies, such as unclear logic, and improve my code’s readability and performance. As a result, I now believe that developers don’t need to know every detail, but they do need a strong understanding of high-level concepts and system design. With that foundation, AI can be used effectively for tasks like refining syntax, optimizing performance, and exploring alternative approaches. Moving forward, I plan to continue using AI as a support tool in my programming. Instead of avoiding it, I’ll use it when I’m stuck, need clarification, or want to improve my code. This  has made me more confident, in my ability to grow as a programmer.
